# `sloth-private` Starter Template (`example.com`)

Copy this directory outside `sloth` (default `../sloth-private`), replace `example.com`, `example-dns`, and `git@github.com:<you>/sloth-private.git` with your own values, and run the `create-and-seal-*.sh` scripts from `sloth` to generate the `*.sealed.json` manifests inside your private repository.

See [`docs/PRIVATE_OVERLAY.md`](../../docs/PRIVATE_OVERLAY.md) for the complete overlay specification and bootstrap order.
